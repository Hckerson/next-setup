# Printed page

Newsrooms, publishers, schools, consultancies and software documentation. The world's rule is the page someone set: a measure, a folio, a running head, a hierarchy a reader trusts.

## Artefacts

| Artefact | Can supply |
| -------- | ---------- |
| Newspapers (masthead, datelines, bylines, columns, rules between stories) | A grid, rules as elevation, a dateline as a numeric style |
| Books (running heads, folios, chapter openings, footnotes) | Margins, a page furniture system, a note device |
| Journal articles (abstract, numbered sections, figures, references) | Section numbering, figure captions, citation as navigation |
| Textbooks and workbooks (exercises, answers, margin notes) | An exercise anatomy, a margin column, progress by chapter |
| Syllabus and timetables (schools) | A term grid, a week as a section |
| Reports and briefs (consultancies) | An executive summary block, exhibit numbering |
| Manuals and reference cards (software) | A keyboard or command notation, a two-column reference |

## Standards

- Editorial style guides (a house style for numbers, dates and capitals) as the source for casing and figures.
- Citation styles (author-date, numbered) for references.
- Reading measure and leading conventions; the platform's own guidance for documentation.

## Archetype pressure

Page (a long read), type (roles, measure, notes), patterns (contents, figures, citations), rows (articles, lessons, results).

## The category template

A hero with a laptop mockup, flat illustrated people with purple limbs, three feature cards with icons, "Empower your team", a testimonial carousel; for news, a red breaking banner over a stock city.

## Stage notes

`print-catalogue` takes the publication as an object that moves like a machine; `paper-cut` takes the page in layers; `colour-field` takes an issue's or a course's colour.
