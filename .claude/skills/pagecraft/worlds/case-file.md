# Case file

Patients, claimants, clients, applicants, children and the bereaved. The world's rule is a duty of care: the matter is kept in order, every step is recorded, and the person is never lost behind the form.

## Artefacts

| Artefact | Can supply |
| -------- | ---------- |
| Folders and files (tabbed folders, colour-coded filing labels, file numbers) | A tab as a shape and a chrome model, a colour code with a job (by letter, by year) |
| Forms (numbered questions, boxes for each character, a declaration and signature) | Form anatomy, step numbering, a box-per-field input style |
| Clinical charts (observation charts, medication administration records, triage tags) | Status vocabulary from a real scale, a gridded record, time down the side |
| Legal papers (pleadings with line numbers, dockets, citations, exhibits) | A margin numbering device, citation as a numeric style, exhibit labels |
| Date stamps and receipt stamps (RECEIVED, with the date and an office) | A mark for a step done, used once per step |
| Index cards and registers | Row anatomy (name and reference first), a card shape |
| Orders of service, memorial cards (funerals), care plans (social care) | A gentle register inside the same world: type with time, few marks |

## Standards

- **GOV.UK Design System** and **USWDS**: proven form patterns (one thing per page, check answers, error summaries). Use their properties; never ship their look as a brand.
- **Manchester Triage System** and **NEWS2**: real five- and four-band scales for urgency.
- **WCAG 2.2 AA** as a floor, and plain-language guidance for forms; duty-of-care sectors are audited on it.
- Records conventions: who, when, what changed, kept visible (an audit trail is part of the interface).

## Archetype pressure

Forms and modals (long forms, saving and returning, check answers), marks (a step's state, an urgency band), rows (cases, appointments, residents), page (a calm reading page for one person's matter).

## The category template

A stock photo of a smiling doctor, family or handshake, teal and white, a shield or a heart icon, scales of justice and a gavel, rounded cards with "Our services", a chat bubble in the corner.

## Stage notes

`paper-cut` takes the folder, tabs and forms as stepped paper; `print-catalogue` takes the register book; `daylight-location` must be the real room (a ward at the morning round, a registry counter), never a stock interior.
