# Live board

Departures, odds, prices, scores and lobbies. The world's rule is that the latest value replaces the last, in public, and everyone reads the same board at once.

## Artefacts

| Artefact | Can supply |
| -------- | ---------- |
| Split-flap departure boards | Motion (a value flips, it does not fade), a fixed-cell numeric style, a dark board ground |
| LED dot-matrix destination signs and platform displays | A pixel or segment face for figures only, an amber or green emitted accent |
| Printed railway and bus timetables | Dense tabular rows, footnote symbols, a timetable face |
| Wayfinding signs (platform numbers, line colours, pictograms) | A colour system with jobs (line colours), a signage face, numbers in plates |
| Manual and electronic scoreboards, tote boards | Display figures, the board's grid as a layout, the period or quarter as a section |
| Tickets, boarding passes and betting slips | A stub and tear as a shape, row anatomy (from, to, time, seat or stake) |
| Ticker tape and exchange boards | Up and down marks, a horizontal crawl confined to one band |

## Standards

- Wayfinding systems of real networks (line colours, pictogram sets, signage faces such as the transport and DIN families) as sources, never as copies of one city's identity.
- **IATA BCBP** fields for a boarding pass; **GTFS** fields for transit (route, stop, headway).
- Market conventions: up and down colours differ by region (red is up in several East Asian markets), so a direction needs a shape as well as a colour.
- Responsible-gambling rules where they apply: limits and time spent shown, never hidden.

## Archetype pressure

Rows (a board row is the product), motion (a value change has to be noticed without alarming), marks (delayed, boarding, suspended, live), console (a dense board on a phone).

## The category template

Black with neon green and red candlesticks, glowing grid lines, a glassmorphism coin, "trade the future"; for transport, a stock photo of a train at blur speed; for sport, a player cut-out on a dark gradient with a lightning bolt.

## Stage notes

`night-luminous` takes the emitted board in a dark hall (the board is the light, so it is earned); `miniature-world` takes the network as a model railway or a tabletop map; `colour-field` takes the line colours as fields.
