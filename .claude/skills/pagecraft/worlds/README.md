# Worlds

A world is the material culture a sector already works in: the documents it signs, the panels it reads, the signs it obeys, the standards it is audited against. It is where a build's instances come from (`differentiation.md`, Property versus instance), so a farm co-op and a law firm stop borrowing their accent, type and status marks from the same software exemplars.

A world is not a look. Two builds in one world share sources, never a result: the draw (`tools/draw.mjs`) deals their positions on the nine axes, and the fingerprint gate keeps them apart. The register (`registers/`) is still the family of decisions and the evidence for the bar; the world is what fills it.

Each sector's world is recorded once, in `docs/economy-coverage-map.md`. Change a fit there, never here.

## Every world file has

- **Artefacts:** the real objects of the sector, and which axis each can supply. A build takes its instances from these, at least three candidates per cue (`differentiation.md`).
- **Standards:** the published standards the sector uses for colour, symbols, type and status. A status vocabulary taken from a real standard is a domain source; one taken from a component library is a default.
- **Archetype pressure:** the layers the sector's interface stresses most, so styleframes cover them first.
- **The category template:** what a template marketplace or a stock library returns for the sector. It is the detector for CONV-G4-3 (`generations.md`): a frame that reproduces it is the fourth generation, however well made.
- **Stage notes:** what the stagecraft sets listed for the sector in the map should take from this world.
- **Captured exemplars:** sites captured with `capture.md`. A world without one says "None captured yet"; never name an uncaptured site as evidence.

## Rules

- A world supplies sources, never values. A hex code, a face or a radius copied from a standard is still chosen and recorded in the brief, with the standard as its source.
- Taking a world's most famous artefact (the split-flap board for transport, the manila folder for law) is the obvious instance. List it, and prefer one the earlier builds in that world have not used (`references/fingerprints.md`, column World source).
- A sector that strains its mapped world takes a second one, recorded in the brief with the reason.
