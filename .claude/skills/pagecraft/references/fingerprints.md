# Fingerprints

One row per shipped build. A new build differs from every row on at least 4 of the nine axes (`differentiation.md`), and `tools/draw.mjs` strikes every value used here. Axis cells use the ids in `tools/menus.json`; World source names the artefact that supplied the signature device, so the next build in the same world takes another. The measured columns come from `stagecraft/tools/shoot.mjs --fingerprints` on the shipped page and feed its `--compare` gate.
