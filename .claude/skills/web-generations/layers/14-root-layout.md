# Layer 14: Root layout

`app/layout.tsx`. The document: fonts, the global theme class, metadata, providers, global behaviour.

**Upstream:** Token, Scale class, Portal layout. A recurring tell here is usually inherited from these layers: trace it there and fix it once, not once per file here.

## Tells

## Floor versus baseline

A competent fourth-generation root is correct and fast: fonts load, providers mount, metadata exists. It lacks decisions: a type voice chosen rather than inherited from the starter, each shipped theme designed and resolved before paint, and global behaviours (reduced motion, focus, forced colours, selection, scroll) set as part of the system. Which faces and which themes belong to the register.

## Baseline

Every register meets these. Counts are of the 18 exemplars (`references/classification-ledger.md`, section 14).

- **ROO-B1. Every shipped theme designed.** Each theme the product ships is its own ladder and depth recipe, and the root declares `color-scheme` for it. Shipping one theme, or dark sections chosen by content, is a recorded decision. `(S 9/18)` Apple ships no `prefers-color-scheme` and flips dark sections by content: recorded, not a gap. See TOK-B16.
- **ROO-B2. Theme before paint.** The stored or system theme resolves before first paint; there is no flash of the wrong theme. `(J, thin)`
- **ROO-B3. A chosen type voice.** The type voice is chosen and recorded in the brief, not the starter's default, and display and body differ on at least two axes (size, family or cut, weight, tracking, leading). A second face is register. `(S)` 11 of 18 use a distinct display face, cut or axis; Things (system UI only: size, weight, leading), Ableton (Futura only: size, weight) and Vercel (Geist Sans plus Mono: tracking, leading) run one family and pass on axes.
- **ROO-B4. Scripts get their own settings.** Where the product is localised, each script has its own fallback stack, and leading and tracking are set per script. `(S 2/18, thin)` Apple's per-language stacks; Wise's stacks for Chinese, Korean, Thai and Hebrew, with display leading from 0.85 for Latin to 1.45 for tall scripts.
- **ROO-B5. Reduced motion, globally and per component.** The root honours `prefers-reduced-motion` globally and each moving component has its own variant. Where code waits on a transition to end, the reduced duration stays above zero. `(S 14/18)` Duolingo's web app has none: a defect. Nothing's `0s` override risks stranding exits that wait on `transitionend`.
- **ROO-B6. Global focus without JavaScript.** The root sets a designed `:focus-visible` style that meets the focus baseline (CHR-B9) in CSS alone; nothing removes outlines globally without a CSS replacement. `(S)` Defects: Duolingo's global `outline: none`; Aesop's `outline: none !important` with a JavaScript highlighter; Teenage Engineering's reset (UNVERIFIED).
- **ROO-B7. Forced colours.** The document stays usable under `forced-colors: active`: focus and boundaries drawn by shadow or background get a transparent outline or a system colour. `(S 2/18, thin)` Aesop (10 or more queries), Nothing (a transparent 2px outline).
- **ROO-B8. Global behaviours set.** Scroll padding clears the sticky chrome (CHR-B5), `scroll-behavior` resets under reduced motion, a selection colour role is set per theme, and the scrollbar is considered. `(S 3/18, thin)` Things (scroll reset), Pudding (selection token per theme); Aesop's entry in this row is forced colours, ROO-B7.
- **ROO-B9. Root error and not-found.** `error.tsx`, `global-error.tsx` and `not-found.tsx` exist at the root and use the app's tokens and chrome. `(J, thin)` Production code had portal errors but no root boundary, which is the gap this catches.
- **ROO-B10. Metadata template.** The root holds a title template, a default description and a branded share image, which each route fills (PAG-B4). `(J, thin)`

## Techniques

Register-neutral methods, recommended, not required.

- **Theme before paint.** An inline script in `<head>` reads the stored theme and sets the theme attribute and `color-scheme` before first paint; with nothing stored, the system preference decides.
- **Tabular numerals.** Set tabular figures on numeric roles where figures align (Vercel uses `tabular-nums` or Geist Mono on numeric columns). Mercury's and Wise's amount cells were not captured, so this stays a technique until they are.

## Token roles this layer needs

Display and text font roles with their axes; per-script fallback stacks and leading; `color-scheme` per theme; scroll padding for the sticky chrome; selection and scrollbar colours per theme; focus colour; reduced-motion defaults; forced-colours fallbacks.
