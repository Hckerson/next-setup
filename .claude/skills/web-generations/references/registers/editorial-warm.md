# Registers research: EDITORIAL and WARM UTILITY

Method. Shipped stylesheets were downloaded with curl and read for custom properties and computed values: press.stripe.com `v1-*.css` (34 files on b.stripecdn.com), pudding.cool `_app/immutable/assets/*.css` (5 files), notion.so `_next/static/chunks/*.css` (17 files, about 4,060 unique custom properties), culturedcode.com `/global/shared/2024-02-20/shared.css` and `/things/2024-01-20/things.css`. Notion app screens and Things iOS screens were read from Mobbin. Contrast ratios were computed by me (WCAG relative luminance). Tags: Q = QUALITY, R = REGISTER. Anything not measured is marked UNVERIFIED.

Caveats that apply to everything:

- All CSS is from MARKETING sites. For Notion and Things the app is seen only through Mobbin screenshots (no computed values). Marketing numbers must not be read as app numbers.
- Alpha colours were flattened onto white for contrast, so those ratios are approximations (marked "about").
- WebFetch returns text only; visual claims come from CSS or Mobbin images.

## EDITORIAL register

**Point of view.** The page is a publication: the content object (a book, a story) is the hero and the interface is paper around it, so typography, per-object colour and pacing do the work that chrome does in a tool.

**Differentiation axes**

| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |

**Failure mode (the AI tell).** A serif display font on a cream or black page with centred text, one hero image, and equal-height sections. It copies the surface (serif plus warm neutral plus big headline) and drops what makes editorial work: a measure, a reading order, and per-object identity. Concrete tells: every section on the same background; one accent used everywhere (Stripe Press changes the whole page colour per object); italics used as decoration instead of a role (Stripe Press uses Headline italic for labels, author lines and descriptions consistently); no body-to-display jump; no considered line length.

### Editorial: QUALITY (expect in other registers)

1. Type roles each with family, weight, style, leading.
2. A stated reading measure (Pudding 720 and 1280 tokens; Stripe Press 380 to 440px text columns).
3. A reduced-motion path and focus-visible policy with skip link.
4. Named easing and duration by distance.
5. Content structure per entity type.
6. A designed fallback for the signature device.

### Editorial: REGISTER

Per-object colour, serif display, italic as a role, near-square corners, no chrome, long measure, shelf or essay as navigation, one hard shadow instead of a ladder, pure grey neutrals (Pudding).

## WARM UTILITY register

**Point of view.** A tool that feels like a calm, human object: warm or softly tinted neutrals, one friendly blue, soft low-alpha shadows and generous radii, so daily work feels like handling paper rather than operating a console.

**Differentiation axes**

| Axis                | Position                                                                                                                                                                                                                            | Evidence                                           |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Neutral temperature | Notion: warm greys `#f9f9f8, #f6f5f4, #dfdcd9, #a39e98, #78736f, #615d59, #494744, #31302e, #191918`. Things: blue-grey tints `#fbfcfe, #f2f5f7, #eeeff2, #e6e8ec, #d5d9de`                                                         | notion `--tatami-color-gray-*`; things `.has-*-bg` |

| Type voice          | Notion: house sans (NotionInter, variable weights 420, 520, 620, 680) with Lyon Text serif and iA Writer Mono as alternates. Things: system UI font only                                                                            | CSS                                                |
| Density             | Mid. Things marketing: 440px hero column, 900px container. Notion app: small quiet UI text (Mobbin, not measured)                                                                                                                   | CSS, Mobbin                                        |
| Shape language      | Soft. Notion 5px, 6px, 12px; button radius is a token that can be 0 or round. | Elevation recipe    | Layered, very low alpha, large blur                                                                                                                                                                                                 | CSS                                                |

| Chrome model        | Notion app: warm-grey left sidebar (about 18 to 20 percent of the preview width, approximate) plus an optional right AI panel. Things iOS: no tab bar, a floating plus button and a dark action pill on selection                   | Mobbin                                             |

**Failure mode (the AI tell).** "Friendly SaaS": cream background, `rounded-xl` cards with `shadow-sm`, pastel blobs, emoji in headings, one blue button. It copies warmth as a colour and drops the discipline: neutral temperature as a system (greys, alpha washes, hairlines and shadows all tinted the same way), shadows built from several faint layers, and very few surfaces. Concrete tell: a beige page with pure-black shadows and cool-grey borders, or a default 12px radius on everything.

## Cross-register read

- Properties found in all four exemplars (strong QUALITY candidates): distinct type roles, a reduced-motion path, a focus indicator, separation by hairline or surface step (never a heavy border), one decision mechanism that parameterises the page (per-object colour pair; semantic token layer; navy-ink alpha), a designed fallback or dark state for the signature device.
- Existing (S) criteria that premium exemplars break, so they read as REGISTER: one accent, luminance ladder, alpha-only borders, negative display tracking, one-line row, sidebar chrome, 4 or 8 base, two-layer focus ring, 4 to 12px radius, 3x display jump, exit faster than enter.
- Quality properties these exemplars partly fail: measured contrast. Things link 4.31:1, Notion 40% text about 2.85:1, Stripe Press 2 of 21 pairs under 4.5, Pudding focus ring 1.66:1 on white. Premium here does not imply passing contrast, so the skill's measured-contrast rule is a stricter bar than these references and should stay a QUALITY rule.
