# Set: print-catalogue

**Point of view.** A printed object that moves like a machine: plates, registration, halftone, a fold. Flat, exact and tactile.

**Core axes.** Flat plates with print texture, mechanical motion (slides, folds, flips) rather than camera, type as image.
**Free axes.** Ink palette, plate count, grid, how literal the print process is.

| Rule     | Realisation                                                                              |
| -------- | ---------------------------------------------------------------------------------------- |
| Light    | None cast; the page is lit evenly, depth is overlap and registration                      |
| Ground   | Paper stock, changing between spreads                                                     |
| Lens     | A fixed flat view; motion is in the plates                                                |
| Mass     | A fold has a crease and a settle; a slide has a stop                                      |

**Failure mode.** A texture overlay on an ordinary page with no mechanical motion.

**Exemplars.** None captured yet.
