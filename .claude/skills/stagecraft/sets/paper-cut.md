# Set: paper-cut

**Point of view.** Made by hand: layered cut paper, stepped motion, visible depth between sheets. Imperfect on purpose.

**Core axes.** Discrete layers with real gaps between them, a stepped time model (about 12 frames per second), an edge that shows its material.
**Free axes.** Palette (from the client), type voice, how rough the cut is.

| Rule     | Realisation                                                                                |
| -------- | ------------------------------------------------------------------------------------------ |
| Light    | Soft top light; each layer casts a short shadow onto the one below                         |
| Ground   | The back sheet; changes colour between shots                                               |
| Lens     | Locked-off, flat, slight parallax between layers                                           |
| Mass     | Stepped: anticipation is a held frame, settle is two small steps                           |

**Failure mode.** Layers moving smoothly at 60 fps with a paper texture: the stepped time model is the point.

**Exemplars.**

- `references/aimees-papercraft-world.md` (captured 2026-11-13): Fifth with gaps. Stepped paper terraces in a room whose colour changes by season; copy printed on the walls.
- `references/mr-pandas-paper-portfolio.md` (captured 2026-11-13): Fifth with gaps. One light offsets every cut-out's shadow on a notebook sheet. Same author and pipeline as the first, so the pair is narrow.
