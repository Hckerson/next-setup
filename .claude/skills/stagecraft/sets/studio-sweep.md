# Set: studio-sweep

**Point of view.** The product photographed in a studio, in motion. A seamless sweep of paper or plastic, a light you can point to, and a shadow that proves the actor is on the ground.

**Core axes.** A seamless ground with no horizon, a single named key light with a quality (soft or hard) and a direction, contact shadows that scale with height.
**Free axes.** Ground colour (derived from the actor's colourway), lens length, whether the sweep changes between shots, time model.

| Rule     | Realisation (directions, not instances)                                                       |
| -------- | --------------------------------------------------------------------------------------------- |
| Light    | One key plus a fill; shadow softness is a token; a second light only when the brief names it |
| Ground   | The sweep takes the colour pair of the current variant; it changes when the actor does        |
| Lens     | Long lens, shallow depth; a macro move for detail shots                                       |
| Mass     | Full: anticipation, settle, a shadow that responds                                            |

**Failure mode.** A product on white that spins: MOT-G3-1 and CAM-G1-1. The second failure: a dark ground and a glow, which is another set.

**Exemplars.**

- `references/vero-studio.md` (Vero, captured 2026-11-13): Fifth with gaps. The sweep changes colour with each state; the opening shot floats with no ground.
