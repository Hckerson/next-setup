# Sets

A set is the world the actor plays in. It is not a theme: it is a point of view on light, material, lens, time and ground that a whole build obeys. Each file names its core axes (what defines the set) and its free axes (where any instance a reference shows is only an instance).

`tools/draw.mjs` deals the set, striking those used before. The brief records the world rules (`concept.md`).

| Set                    | Point of view                                              | Suits                                      | Strains for                         |
| ---------------------- | ---------------------------------------------------------- | ------------------------------------------ | ----------------------------------- |
| `studio-sweep`         | The product photographed, in motion                        | Physical goods, apparel, objects           | Services with nothing to hold       |
| `daylight-location`    | The product in the world it is used in                     | Food, travel, outdoor, home, mobility      | Abstract or digital products        |
| `paper-cut`            | Made by hand, stepped, layered                             | Craft, kids, community, food, publishing   | Precision or financial products     |
| `macro-material`       | The material is the story                                  | Fabric, food, cosmetics, metal, packaging  | Anything whose appeal is its shape  |
| `miniature-world`      | The world is small and the actor travels it                | Logistics, mobility, places, services      | Single objects with no setting      |
| `print-catalogue`      | A printed object that moves like a machine                 | Publishing, heritage, retail, education    | Anything that must feel immersive   |
| `technical-drawing`    | The product explained as a drawing that builds itself      | Engineering, hardware, B2B, medical devices | Fashion and food                   |
| `night-luminous`       | Light is the subject, in the dark                          | Audio, nightlife, optics, devices          | Anything warm, human or everyday    |
| `colour-field`         | A flat saturated field; the actor is the only depth        | Brands with a strong colour, beverages, apparel | Products that need a place to live |

## Rules for every set

- A set file states its light source, ground, lens and time model in one line each, and which are core.
- The ground colour is derived from the actor's variants and the set; no set has a fixed ground.
- `night-luminous` is one set of nine. Choosing it needs a reason from the domain; "it looks premium" is not one.
- A set without a captured exemplar says so. Do not name a site that was not captured.
