# Set: colour-field

**Point of view.** One flat saturated field, hard edges, and the actor as the only depth. The page is a colour that changes with the actor.

**Core axes.** A flat ground with no gradient, hard-edged shadows or none, the field changing colour with the actor's variant.
**Free axes.** The palette, shape of the blocks, whether blocks move, type voice.

| Rule     | Realisation                                                                              |
| -------- | ---------------------------------------------------------------------------------------- |
| Light    | A hard source with a crisp cast shadow, or none (flat)                                    |
| Ground   | A field per variant; blocks of colour slide in as the ground changes                      |
| Lens     | Locked-off or orthographic                                                                |
| Mass     | The shadow is the weight: it lengthens, shortens and snaps to the ground on landing       |

**Failure mode.** A gradient background with a drop shadow: that is the fourth generation again, in colour.

**Exemplars.** None captured yet.
