# Set: miniature-world

**Point of view.** A small world seen from above and slightly aside, the actor travelling through it. Tilt-shift scale, set pieces that react.

**Core axes.** An isometric or high three-quarter camera, a defined world with places, set pieces that respond to the actor passing.
**Free axes.** Palette, level of detail, whether the world is a city, a table, a map or a body.

| Rule     | Realisation                                                                              |
| -------- | ---------------------------------------------------------------------------------------- |
| Light    | A single sun with long soft shadows; shadows are the scale cue                           |
| Ground   | The world's own surface, changing between places                                          |
| Lens     | Orthographic or long, with a depth-of-field band for the tilt-shift effect               |
| Mass     | The actor's weight is read in how the world responds                                      |

**Failure mode.** Generic low-poly city blocks that have no connection to the client.

**Exemplars.** None captured yet.
