# Set: night-luminous

**Point of view.** Light is the subject, in the dark. The actor is lit by something you can point to and is seen by what it emits or reflects.

**Core axes.** A dark ground chosen for a reason in the domain, an emitting or reflecting light source that is named, an accent spent only where the light is.
**Free axes.** The source, its colour, its movement, how much bloom (none is allowed).

| Rule     | Realisation                                                                              |
| -------- | ---------------------------------------------------------------------------------------- |
| Light    | A named source: a screen, a lamp, a flame, a lens. Glow only where that source is        |
| Ground   | Near-black derived from the product or its environment, not a default                    |
| Lens     | Long and shallow, so the light falls off                                                 |
| Mass     | Light has inertia: it swells and decays, it does not blink                               |

**Failure mode.** The stage default cluster itself: a field of fine lines, bloom, one accent and a light serif. SET-G4-1 and SET-G4-2 fire on it. Using this set needs a reason from the domain, and the draw never picks it twice in a row.

**Exemplars.** None captured yet.
